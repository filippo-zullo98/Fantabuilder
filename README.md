# 🏆 Tool Consigli Asta Fantacalcio

Tool interattivo per gestire l'asta del fantacalcio con consigli in tempo reale basati su indici di convenienza.

## ✨ Funzionalità

- 📊 Dashboard in tempo reale con budget e acquisti
- 🎯 Consigli intelligenti basati su indice di convenienza
- 🧤 Regola automatica dei portieri (acquisto di tutti i portieri della stessa squadra)
- 📈 Gestione fasi: Portieri → Difensori → Centrocampisti → Attaccanti
- 💰 Inserimento prezzo personalizzato per ogni acquisto
- 🔄 Tracciamento acquisti e budget residuo
